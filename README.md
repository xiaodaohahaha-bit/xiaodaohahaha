# JC UX/UI Portfolio

A responsive UX/UI portfolio built with React, Tailwind CSS, Vite, and Three.js.

## Live demo

[jc-ux-ui-portfolio.netlify.app](https://jc-ux-ui-portfolio.netlify.app)

## Highlights

- Portfolio pages preserve the proportions and layout of the original design.
- The project directory links to the Damai, Cainiao, and Wondershare case studies.
- Directory cards use an edge-only glow that follows each card's original rounded shape.
- Project pages include glass-style navigation controls.
- The contact page supports pointer and touch-driven grid distortion.
- Desktop and mobile layouts are supported.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Netlify configuration is included in `netlify.toml`.
